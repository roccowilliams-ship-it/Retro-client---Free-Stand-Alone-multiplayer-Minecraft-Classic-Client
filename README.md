RetroClient is a free, fan-made recreation of Minecraft's early 2009 "Classic" version, built from scratch to be incredibly lightweight and community-driven.

• Completely Free: There are no microtransactions, paywalls, or hidden fees. You get full access to the game and server hosting tools for free.
• Incredibly Lightweight: The game client is written in C and is tiny (often under 5MB). It runs smoothly at high framerates on almost any hardware, including old laptops, mobile devices, and even directly inside web browsers.
• Thriving Custom Servers: The multiplayer scene is highly active. Servers feature custom game modes like Zombie Survival, Lava Survival, Capture the Flag, and massive free-build creative worlds.
• Massive Customization: It features extensive modding support, custom texture packs, custom skins, and custom blocks that go far beyond what the original Minecraft Classic offered.
• Pure Nostalgia: It perfectly captures the simple, blocky, and creative atmosphere of early 2000s sandbox gaming without the complexity of modern survival mechanics.
